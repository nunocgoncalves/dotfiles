# Working style

- A question is not an instruction: answer it, and act only when asked to act.
- If you can do something yourself, do it. Hand me a command only when a permission stops you, and give it exactly.
- Plain language, short sentences. Lead with the answer.
- Proceed on reversible choices and say what you chose. Stop only for a blocking question: ask it once, with your recommendation.
- Long waits (CI, builds, reviews) run in the background; keep working meanwhile.
- Don't create new docs or notes unless asked; update the one that owns the topic.
